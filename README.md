# 📚 Smart Study Planner (Greedy + Dynamic Programming)

## 🚀 Project Overview

The **Smart Study Planner** is a Python-based project that helps students efficiently plan their study schedule within a limited time. It uses **Greedy Algorithms** and **Dynamic Programming (0/1 Knapsack)** to maximize the total marks or priority of selected subjects.

This project demonstrates the real-world application of algorithmic techniques in decision-making and optimization.

---

## 🎯 Objectives

* Optimize study time allocation
* Maximize marks/priority within limited time
* Compare **Greedy vs Dynamic Programming approaches**
* Provide an efficient and practical solution for students

---

## 🧠 Algorithms Used

### 1. Greedy Algorithm

* Selects subjects based on **marks per unit time**
* Fast and simple
* May not always give the optimal solution

### 2. Dynamic Programming (0/1 Knapsack)

* Finds the **optimal combination of subjects**
* Ensures maximum marks within time constraint
* More accurate than Greedy approach
